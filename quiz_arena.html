📖 Quiz Arena — User Guide

2–8 students • one device per player recommended

📗 1. Central Question Bank

The site owner sets one Google Sheet inside quiz_arena.html. Every host automatically fetches that same bank.

Q_ID | Question | OptionA | OptionB | OptionC | OptionD | CorrectAnswer | ImageURL

Players never need to paste or know the Sheet link.

🏠 2. Host creates the game

  1. Enter your name.
  2. Optionally change Host Settings.
  3. Press Host Game.
  4. The latest configured Google Sheet is fetched automatically before the game room is created.
  5. Share the code/link.
  6. Press Start when at least one guest joins.

🎯 3. Guests join

  1. Open the shared game link.
  2. Enter your name.
  3. Press Join Game.
  4. No Google Sheet is needed on guest devices.

🎤 4. Quiz Master

Each round a different player becomes Quiz Master. The Quiz Master sees the question and options first, then presses 📤 Ask Everyone. The Quiz Master does not answer that round.

⏱ 5. Answer and score

Tap A/B/C/D before time ends. The guest waits for 🔒 Answer locked • received by host. Correct score, fastest bonus and Quiz Master bonus are calculated by the host automatically.

😀 6. Sounds & reactions

Join, question start, countdown, correct/wrong and final winner have different sounds. Emoji reactions float across all connected players. The host can disable reactions.

🛡 7. Fair Play

If enabled, leaving the game tab/app before answering locks that round. Copy, cut, selection and right-click are blocked during active rounds. This is classroom fair-play protection, not a secure examination system.

🔐 8. Misuse Guard

Duplicate player names and duplicate browser/device joins are blocked. Host can lock new joins or remove a player. Emoji spam is rate-limited, malformed answer packets are ignored, game codes are longer, repeated Fair-Play strikes can auto-remove a player, and rooms expire automatically.

🖼 9. Images

If ImageURL is present, the image appears above the options for Quiz Master and players. Use a direct, publicly accessible HTTPS image URL. Leave the cell blank for text-only questions.

Important: The game reduces casual cheating, but a browser game cannot prevent a second device, another person, screenshots, or a determined user from using developer tools.
